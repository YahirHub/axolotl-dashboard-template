# Tarea 03 — SQLite + GORM

## Objetivo
Configurar SQLite como DB por defecto a través del .env y validar persistencia con ORM/migración.

## Criterios de aceptación
- DB_CONNECTION=sqlite.
- DB_DATABASE configurable.
- driver SQLite instalado.
- migración/modelo de prueba.
- smoke test de lectura/escritura.
